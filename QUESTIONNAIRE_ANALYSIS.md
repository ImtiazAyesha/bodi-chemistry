# 20-QUESTION QUESTIONNAIRE - COMPLETE LINE-BY-LINE ANALYSIS

## 📋 OVERVIEW

The **20-Question Questionnaire** is a critical component of the Bodi Kemistri wellness assessment platform. It captures subjective health data about the user's postural history, pain points, lifestyle habits, and physical awareness. This questionnaire contributes **20%** to the total Bodi Kemistri wellness score.

---

## 🎯 PURPOSE & DESIGN PHILOSOPHY

### Core Objectives:
1. **Symptom Awareness**: Identify current pain points and discomfort areas
2. **Habit Tracking**: Assess lifestyle factors that impact posture and wellness
3. **Physical Activity**: Evaluate exercise and mobility practices
4. **Proprioception**: Measure body awareness and balance capabilities

### Design Principles:
- **Binary Simplicity**: All questions use Yes/No format for quick, decisive answers
- **Comprehensive Coverage**: Addresses full-body health from head to toe
- **User Engagement**: Paginated interface (5 questions per page) prevents overwhelm
- **Progress Transparency**: Real-time progress bar and counter maintain motivation

## 🧮 SCORING ALGORITHM

### Starting Baseline
**Base Score**: 50 points

### Scoring Rules

#### ✅ Positive Habit Questions (4 total)
**Questions**: 7, 15, 16, 19
- **"Yes" answer**: +5.0 points (rewarding good habits)
- **"No" answer**: -2.5 points (penalizing absence of protective factors)

#### ⚠️ Pain/Issue Questions (16 total)
**Questions**: 1, 2, 3, 4, 5, 6, 8, 9, 10, 11, 12, 13, 14, 17, 18, 20
- **"Yes" answer**: -2.5 points (symptom present)
- **"No" answer**: +2.5 points (symptom absent)

### Final Score Calculation
```javascript
score = clamp(50 + sum(all_adjustments), 0, 100)
```

### Score Range
- **Minimum**: 0 (worst possible health indicators)
- **Maximum**: 100 (optimal health indicators)

### Example Calculations

#### Best Case Scenario:
- All 4 positive habits = "Yes" → +20 points
- All 16 pain/issues = "No" → +40 points
- **Total**: 50 + 20 + 40 = **110 → clamped to 100**

#### Worst Case Scenario:
- All 4 positive habits = "No" → -10 points
- All 16 pain/issues = "Yes" → -40 points
- **Total**: 50 - 10 - 40 = **0**

#### Average Scenario:
- 2 positive habits "Yes", 2 "No" → +5 points
- 8 pain/issues "Yes", 8 "No" → 0 points
- **Total**: 50 + 5 = **55 points**

## 🔄 USER FLOW

### Step-by-Step Journey

1. **Entry**: User lands on Page 1 after completing camera assessment
2. **Question Interaction**:
   - Read question text
   - Click "Yes" or "No"
   - Visual feedback: card highlights, button changes color
   - Progress bar updates
3. **Page Navigation**:
   - "Next" button disabled until all 5 questions answered
   - Click "Next" to advance
   - "Previous" available to review/change answers
4. **Completion**:
   - Final page shows "Continue to Instructions" button
   - Button disabled until all 20 questions answered
   - Click to submit and proceed to camera setup
5. **Score Calculation**:
   - Automatic calculation on submit
   - Score stored in app state
   - Contributes 20% to final wellness score

## 📊 INTEGRATION WITH TOTAL SCORE

### Weighting Formula
```javascript
finalScore = (faceScore × 0.3) + (bodyScore × 0.5) + (questionnaireScore × 0.2)
```

### Component Breakdown
- **Face Assessment**: 30% (objective facial symmetry analysis)
- **Body Assessment**: 50% (objective postural analysis - 4 stages)
- **Questionnaire**: 20% (subjective self-reported data)

### Why 20%?
The questionnaire provides crucial **subjective context** that cameras cannot capture:
- Internal pain experiences
- Lifestyle habits
- Historical injuries
- Functional limitations
- Self-awareness levels

This balances the objective visual data with the user's lived experience.
